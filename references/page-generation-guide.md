# S4 漫画页生成

目标：把《分镜脚本.md》逐页变成 PNG。每页一次生成调用，带设定图参考。

每页提示词以 [page-base-prompt.md](page-base-prompt.md) 的三段式结构为准
（角色参考 → 页面内容 → 一致性提醒），基础规格（格线/气泡/文字规范）不再逐页重写。

## 单页提示词结构

1. **画风基准**：原样复制总表的画风基准段
2. **版式声明**：页漫必须写明格数和非对称位置/面积（如“页顶贯通出血横幅、中段左宽右窄、页底左小右大”）；条漫写明单屏内容
3. **逐格内容**：按分镜脚本逐格写——景别、构图、出场角色、表情/气势/状态
   （按剧情节拍写足：血污、嘶吼、眼神方向、颤抖……见 style-guide.md 表情节拍）
4. **角色引用**：写明参考图用途，如「参考图1为角色林晚的三视图，本页第1、3、5格的林晚必须与此形象完全一致」
5. **文字内嵌**：每个气泡/旁白框逐字给出，标明归属格与位置；简繁跟用户确认
6. **文字铁律**：明写"本页唯一允许出现的文字是上列台词/旁白原文与拟声；
   禁止任何自创对话台词，禁止编造角色说的话，禁止 ①②③④ 序号徽章出现在画面或分格角落"
7. **禁止项**：不得添加分镜之外的角色、不得改动台词、不得出现水印

执行 [style-guide.md](style-guide.md) 去AI味清单：空质量词与泛风格词清零；每格按分镜写入
光源方向与构图偏移；人物带 2 项不完美；整页带 1 种媒介质感锚（与风格基因的"媒介质感"一致）。
黑白漫页面明确写网点与涂黑要求（`灰阶用网点纸质感、关键格涂黑反白`）。

## 模型与版式

- **优先模型：`gpt-image-2.0`**；如后端只提供旧别名 `gpt-image-2`，可回退。
- 页漫推荐 `1024x1536`，质量 `high`。
- 页漫提示词加入硬性禁令：禁止默认 2x2 网格、禁止四格等宽等高从上排到下、禁止每格都是完整横条。
- 版式声明要足够具体，模型才能理解“错落/斜切/出血/splash”，只写“动态一点”通常无效。

## 参考图传入规则

- **清单驱动，禁止手工配图（硬性）**：每页的参考图清单从 `检查清单.md` 对应行读取，
  传入前逐项比对——清单列出的每个 ID 都必须有一张真实 PNG 作为参考图传入。
  校验失败（缺文件/漏传/传错形态）立即停止出该页，回 S2 补图或修清单，不允许
  "这页应该没差"式的跳过。事故教训：分镜标注了某配角的设定图，生成时参考图漏传，
  结果该角色被画成完全陌生的形象，整页作废。
- 出场角色：三视图必传；表情集/服装变体按本页需要加传
- **全员图 `CHARACTERS-全员.png` 恒定作为参考图 1**（一图管全员一致性）
- 场景：本页主场景全景图传入；换场景页必传新场景图
- **空间锚定**：反复出镜的场景传`机位图`，分镜每格标"机位#N"，提示词写明机位与人物动线
  （如"参考图2为小巷机位图，本格镜头=机位9（低机位），货车从深处迎面冲来"）；
  需要时可先用图像工具裁出对应格作单格参考
- **数量不设硬上限**（API 支持多图）：必传项由检查清单决定，按锚点强度排序传入——
  角色专属设定图 > 全员图 > 场景/机位图；排序靠前的先传，提示词里按传入顺序引用。
- **真实约束是体积与保真**：参考图传入前统一压缩（生成脚本内置 ≤1152px JPEG，
  防请求体超限 413）；参考图越多单锚保真越稀释，单页 >6 张且出现角色漂移时，
  优先裁切合并低区分度锚（如从全员图裁出本页角色），不允许为控数量砍检查清单必传项。

## 重roll规范（编辑图提示词）

单页重roll时**一次只改一类内容**（光影 OR 表情 OR 版式，不混改），提示词结构：

```
必须保持不变：
- 参考图人物身份、原分镜构图与镜头、台词逐字与气泡归属

只修改：
- 将[原内容]改为[目标内容]，位置在[哪一格/哪一区域]
```

"必须满足"≤4 条、"避免"≤3 条（配额见 page-base-prompt.md 提示词信噪比）。
先改 `prompts/` 里的提示词文件再重roll；重roll后目检顺序：文字 → 人物状态 → 光影 → 版式。

### 错误类型 → 处置手段（先判断，再动手）

| 错误类型 | 首选手段 | 理由 |
|---|---|---|
| 角色画错 / 混入陌生角色 | 整页重roll（先补齐参考图） | 像素级修改换不了人 |
| 文字错字 / 叠字 / 乱码 | 重roll 1 次；不中即转**确定性修字** | 文字渲染是抽卡，重roll 不收敛，还可能把对的改错 |
| 光影 / 局部小瑕疵 | 编辑模式局部改（本节模板） | 代价最小 |
| 版式崩 / 格序乱 | 整页重roll | 结构问题局部改不动 |

**确定性修字（文字错误的标准兜底）**：文字类错误重roll 1 次未中就停手，
改用图像处理做像素级修复——出错气泡区域白底覆盖，按原字号与近似字体写回
正确文字，保存后目检比对。零生成成本、不赌运气、不引入新错。
（典型事故：同一处错字两次整页重roll＋一次编辑模式均未收敛，编辑模式反而把
原本正确的两处台词改错——文字类错误超过 1 次重roll就必转修字。）

## 文字校对流程

1. 全章完成后先拼总览图（contact sheet），**压缩到 ≤1MB 的 JPEG 再送目检**
   （原始 PNG 体积大，直接送检容易撞上下文/接口体积限制），再逐页放大检查。
2. 逐格检查四类错误：错字/漏字/乱码/气泡溢出；**自创台词**（模型编造的未列出对话）；
   **序号徽章**（①②③④ 等面板序号入画）；角色与设定图不符。
3. 有错 → 先按「错误类型 → 处置手段」决策表选手段（见重roll规范节）；
   非文字类错误单页最多重roll 2 次，旧图移入 `*-backup-<时间戳>/` 保留。
4. 确定性修字失败（字体/位置无法匹配）→ 该页出无字版，日志记录缺失文字，
   交用户决定后期加字。

## 尺寸与批量

- 页漫：每页 `1024x1536`（跨页大格可 `1536x1024`，以分镜为准）。
- 条漫：每屏 `1024x1536`；需要长图时用图像工具后期拼接，不要求模型一次画完整条。
- 批量 = 逐页循环调用；每页完成立即落盘 `03-漫画页/CH<章号>/CH<章号>-P<页号>.png` 并写日志。

## 断点续跑

开跑前读 `生成日志.md`：已「完成」的页跳过，「失败/无字」的页按日志记录重跑。
全部完成后向用户汇报：本章页数、失败清单、无字页清单，然后停靠——**不自动续做下一章**。

## 交付自查

- [ ] 每页角色与设定图一致（脸、发型、服装）
- [ ] 人物表情/气势匹配剧情节拍（高潮格不吃人设可爱、绝望格不带笑）
- [ ] 无自创台词（全部文字都是分镜列出的原文），无序号徽章入画
- [ ] 格序与分镜一致，阅读顺序正确
- [ ] 台词逐字无误、气泡归属正确
- [ ] 文件名与 ID 对应，日志完整
