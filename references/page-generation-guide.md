# S4 漫画页生成

目标：把《分镜脚本.md》逐页变成 PNG。每页一次生成调用，带设定图参考。

每页提示词以 [page-base-prompt.md](page-base-prompt.md) 的三段式结构为准
（角色参考 → 页面内容 → 一致性提醒），基础规格（格线/气泡/文字规范）不再逐页重写。

## 单页提示词结构

1. **画风基准**：原样复制总表的画风基准段
2. **版式声明**：页漫必须写明格数和非对称位置/面积（如“页顶贯通出血横幅、中段左宽右窄、页底左小右大”）；条漫写明单屏内容
3. **逐格内容**：按分镜脚本逐格写——景别、构图、出场角色、表情动作
4. **角色引用**：写明参考图用途，如「参考图1为角色林晚的三视图，本页第1、3、5格的林晚必须与此形象完全一致」
5. **文字内嵌**：每个气泡/旁白框逐字给出，标明归属格与位置；简繁跟用户确认
6. **禁止项**：不得添加分镜之外的角色、不得改动台词、不得出现水印

执行 [style-guide.md](style-guide.md) 去AI味清单：空质量词与泛风格词清零；每格按分镜写入
光源方向与构图偏移；人物带 2 项不完美；整页带 1 种媒介质感锚（与风格基因的"媒介质感"一致）。
黑白漫页面明确写网点与涂黑要求（`灰阶用网点纸质感、关键格涂黑反白`）。

## 模型与版式

- **优先模型：`gpt-image-2.0`**；如后端只提供旧别名 `gpt-image-2`，可回退。
- 页漫推荐 `1024x1536`，质量 `high`。
- 页漫提示词加入硬性禁令：禁止默认 2x2 网格、禁止四格等宽等高从上排到下、禁止每格都是完整横条。
- 版式声明要足够具体，模型才能理解“错落/斜切/出血/splash”，只写“动态一点”通常无效。

## 参考图传入规则

- 出场角色：三视图必传；表情集/服装变体按本页需要加传
- **全员图 `CHARACTERS-全员.png` 恒定作为参考图 1**（一图管全员一致性）
- 场景：本页主场景全景图传入；换场景页必传新场景图
- **空间锚定**：反复出镜的场景传`机位图`，分镜每格标"机位#N"，提示词写明机位与人物动线
  （如"参考图2为小巷机位图，本格镜头=机位9（低机位），货车从深处迎面冲来"）；
  需要时可先用图像工具裁出对应格作单格参考
- 一次调用参考图以 ≤ 3 张为宜，优先核心锚（主角三视图 + 主场景）；超出部分靠文字锚点描述

## 文字校对流程

1. 生成后逐格放大检查气泡文字：错字、漏字、乱码、气泡溢出。
2. 有错 → 重roll，提示词对出错处加「必须逐字渲染：……」；单页最多重roll 2 次。
3. 仍失败 → 该页出无字版，日志记录缺失文字，交用户决定后期加字或再试。

## 尺寸与批量

- 页漫：每页 `1024x1536`（跨页大格可 `1536x1024`，以分镜为准）。
- 条漫：每屏 `1024x1536`；需要长图时用图像工具后期拼接，不要求模型一次画完整条。
- 批量 = 逐页循环调用；每页完成立即落盘 `03-漫画页/CH<章号>/CH<章号>-P<页号>.png` 并写日志。

## 断点续跑

开跑前读 `生成日志.md`：已「完成」的页跳过，「失败/无字」的页按日志记录重跑。
全部完成后向用户汇报：本章页数、失败清单、无字页清单，然后停靠——**不自动续做下一章**。

## 交付自查

- [ ] 每页角色与设定图一致（脸、发型、服装）
- [ ] 格序与分镜一致，阅读顺序正确
- [ ] 台词逐字无误、气泡归属正确
- [ ] 文件名与 ID 对应，日志完整
