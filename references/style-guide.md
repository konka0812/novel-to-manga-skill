# 风格基因与去AI味指南

每部小说必须有**自己的画风**，不是"日漫风"三个字糊弄过去。AI 出图最大的问题不是画不好，
而是千篇一律的"AI 完美感"：过度光滑、居中对称、均匀打光、滤镜感厚重。本指南解决两件事：
**风格从哪来**，**AI 味怎么压**。

## 一、风格基因（Style DNA）—— 从小说推导，不从模板复制

S1 读完全书设定后，从小说自身的四个维度推导画风，写进《设定总表.md》的「画风基准」段：

| 维度 | 问什么 | 例 |
|---|---|---|
| 题材气质 | 都市/古风/科幻/校园/悬疑？ | 网文吐槽×魔法少女 → 都市奇幻轻喜剧 |
| 时代地域 | 现代中国/民国/异世界和风/西幻？ | 现代中国城市 → 中国学生长相、国内街景元素 |
| 情绪基调 | 热血/治愈/压抑/荒诞/甜？ | 偏执求道+喜剧反差 → 明快但主角眼神要"轴" |
| 叙事速度 | 快节奏爽文/慢热文青？ | 快节奏 → 短格密排、动作戏多、视线流动快 |

推导出的风格基因用**五维**描述（每个维度写具体做法，不写形容词）：

1. **线条**：粗细、抖动/顺滑、勾边深浅（如"外轮廓 2px 重线、内结构 1px 细线、发丝留飞白"）
2. **上色**：赛璐璐/厚涂/水墨/网点灰阶；阴影用色偏紫还是偏棕（如"阴影统一偏紫褐、不上纯黑"）
3. **色彩**：主色+辅色+点缀色的**色相范围**（如"全书主色暖黄+砖红，点缀色只用蓝，禁用紫色系"）
4. **构图气质**：格形偏好、留白习惯、光源方向（如"侧逆光为主、忌正面平光"）
5. **媒介质感**：印刷网点/纸张颗粒/胶片颗粒/干净数码（见下节去AI味）

五维之外必须附**时代地域锚点清单**（教室/街巷/服装的具体道具特征）——
没有清单，"现代中国"四个字挡不住模型默认输出日式教室。清单模板见
[style-dna-template.md](style-dna-template.md)。

> 铁律：主角色系全书固定；每章最多引入一种新场景色。色彩是识别度的最大来源，克制才有风格。

## 二、彩漫 / 黑白漫 —— 用户必选

S1 停靠时让用户二选一，写死进风格基因：

| | 彩漫 | 黑白漫（日式杂志风） |
|---|---|---|
| 灰阶 | 色彩分区+明度分层 | **网点纸**模拟灰阶（58%平网/渐变网/沙网） |
| 强调 | 色相对比 | **涂黑**（大面积黑底反白）+ 集中线 |
| 光影 | 光源色统一 | 高光留白、阴影网点叠层 |
| 动感 | 色彩速度感 | 流线、效果线、速度线 |
| 适配 | 条漫/国漫彩页 | 青年漫/少年漫杂志质感 |

黑白漫不是"彩漫去色"——提示词必须明确要求网点质感与涂黑构图，否则出来是灰蒙蒙的数码灰。

## 三、去 AI 味清单（出图提示词必做）

### 反面清单（禁止出现）

- 空洞质量词：`masterpiece, best quality, highly detailed, 8k, 超高清`——堆这些必出 AI 味
- 泛风格词：`赛博朋克风、动漫风格、唯美插画`——模型只能给你平均值，平均值=AI 味
- 主观形容：`漂亮、华丽、精致、完美`——AI 的"完美主义"正是油腻来源
- 负面堆砌：连续 5+ 条"禁止"是另一种 AI 味——模型顺从性过载，画面要么过素要么乱飘；
  负面只留真正致命的，方向问题靠改肯定句解决

### 正面做法（按优先级）

1. **具体可见特征替代主观词**：不写"一个帅气的男主角"，写"17 岁男生，黑发微乱压住眉骨，
   眼神偏执，白色短袖衬衫皱着、下摆半抽出"。
2. **注入不完美**（AI 完美感的天敌）：`不对称设计`、`衣物褶皱凌乱`、`碎发飘飞`、`环境污渍/磨损`、
   `戏剧性侧光`、`构图偏移不居中`。人物至少注入 2 项，场景至少 3 项。
3. **媒介质感锚**：给画面一种"旧媒介"，如 `90年代漫画杂志印刷质感`、`纸张颗粒`、`轻微套印错位`、
   `手绘线稿感`、`胶片颗粒`。每张图必带一种。
4. **参考锚替代风格描述**：有设计稿就传设计稿做参考（"角色形象严格依据参考图"），比文字风格词有效十倍。
5. **光源与构图破对称**：光源写明确方向（`右侧低角度逆光`）；构图写偏移
   （`人物位于画面左三分之一，右留大面积余白`）。
6. **表情去僵硬**：逐条写动作（`挑眉、嘴角单侧上挑、手指敲桌面`），不写"在说话"。
7. **表情跟剧情节拍走，不跟人设走**：设定特质（娇俏/冷峻/呆萌）只是默认值，
   高潮格必须按当下情绪覆盖——父母坟前称帝的"娇俏脸庞"要写成
   "娇俏脸庞配狠戾睥睨"；情绪链跨格递进（绝望嘶吼→决绝→睥睨），
   逐格写出状态锚（血污/泪水/颤抖/气势姿态），只写"身份保持"救不了平掉的情绪。

### 生成后检查（AI 味三问）

- 光是不是太均匀？→ 补戏剧性光源重roll
- 构图是不是居中对称？→ 偏构图重roll
- 皮肤/材质是不是塑料感？→ 加纸纹/网点/颗粒词重roll
- 表情/气势撑不住本格剧情？→ 补情绪锚（血污/嘶吼/眼神方向）重roll——
  光调得再对也救不了平掉的情绪

单页最多重roll 3 次，仍不行则换构图方案而不是无限微调提示词。
