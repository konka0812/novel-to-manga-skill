# S1 小说拆解方法

目标：产出一份《设定总表.md》，让后续每个阶段只靠它工作，不再回读原文。

## 读取策略

- 长篇先扫章节标记建章级索引，明确每章起止；先精读第 1 卷（或前 10 章）建立设定，其余按需补读。
- 用户点名"只转第 N 章"时，仍要读该章的前后文，设定不能只从单章推断。
- 只处理创作者合法持有、有权使用的作品；设定文档做结构化提取，不整段复制原文。

## 人物卡字段

每个有台词或推动剧情的角色一张卡：

| 字段 | 要求 |
|---|---|
| 姓名/身份 | 原著名 + 身份一句话 |
| 外貌锚点 | 发型发色、眼、体型、年龄感、肤色；具体到可画 |
| 服装 | 主造型 + 场景变体（常服/正装/战斗等） |
| 气质 | 性格如何体现在表情、站姿、习惯动作 |
| 标志物 | 随身道具、武器、配饰 |
| 出场章节 | 首次 + 主要出场，标注第几章 |

分级：

- **主要角色**（第 1 章有台词/戏份）：必须出设定图
- **次要角色**（本卷出场）：写卡，是否出图问用户
- **群演**：不建卡，在画风基准里给一句群演通用描述

## 场景卡字段

| 字段 | 要求 |
|---|---|
| 地点/时代 | 朝代/年代/地域/科技或修炼水平 |
| 空间结构 | 布局、标志物、进出动线 |
| 光线时段 | 日/夜/黄昏；主光源 |
| 氛围 | 情绪基调 + 色彩倾向 |
| 出场章节 | 同人物卡 |

## 世界观背景

- 时代、地理、社会规则、力量体系或超自然要素（如有）
- 影响画面的硬规则要显式写出（如"此世界无热兵器""灵力可见为青色光纹"）

## 画风基准（用户确认环节的核心）

**先读 [style-guide.md](style-guide.md)，风格基因必须从这部小说自身推导**（题材气质/时代地域/
情绪基调/叙事速度四维 → 线条/上色/色彩/构图气质/媒介质感五维），不许拿"日漫风"套模板。

确认流程：
1. 向用户提出 **彩漫 / 黑白漫（网点涂黑）** 二选一（用户要求时才可彩黑白混用）
2. 给出按该小说推导的 2–3 个风格基因方案（各带一句视觉描述），用户选定或修改
3. 最终定稿写进《设定总表.md》「画风基准」段，并附一句群演通用描述

之后所有出图提示词原样引用这段，不再讨论风格。

## 溯源要求

每张卡的每个关键设定标注出处章节（如「黑发（第1章）」），后续审查可回查。
