# S3 章节分镜拆解

目标：把一章小说变成《分镜脚本.md》——一份页级、格级都可直接执行的生产单。

## 版式选择

| | 页漫（日漫/国漫书） | 条漫（国产竖滑） |
|---|---|---|
| 页结构 | 每页 4–8 格，矩形页 | 每屏 1 格，竖向滚动 |
| 节奏单元 | 页翻动 = 节拍 | 留白/黑屏 = 节拍 |
| 阅读顺序 | 右上→左下（日漫）或左上→右下（国漫） | 单列向下 |
| 输出尺寸 | 1024x1536 竖版每页 | 每屏 1024x1536，后期可拼接 |

和用户确认版式后再拆。"日本漫画那种" = 日式页漫；"国产漫画/条漫" = 竖滑条漫。

## 切分方法

1. **场景 → 页**：地点或时间切换即页边界；一场戏至少 1 页。
2. **节拍 → 格**：一个动作/一句台词/一次反应 = 一格；情绪重锤可占大格或独占页。
3. **节奏控制**：紧张戏短格密排，抒情戏大格留白；每 3–5 页安排一个钩子（悬念/反转/新信息）。
4. **信息取舍**：心理描写转成表情特写或旁白框；大段环境描写压成 1–2 格场景格。
5. **轴线意识**：同场景内保持角色左右关系不跳轴；跨页延续动作时首格须重复定位信息。

## 格形语言（コマ割り）

格子形状本身在叙事，拆页时先选格形再填内容：

| 格形 | 情绪语义 | 用法 |
|---|---|---|
| 横宽格 | 时间流动、纵深、平稳 | 过场、行走、环境交代 |
| 竖长格 | 压迫、速度、坠落 | 冲突升级、强敌登场 |
| 斜切格 | 动荡、冲击 | **整页最多 1 处**，滥用读者会晕 |
| 大格/无框 | 情绪爆点、揭示 | 每页最多 1 个，留给本页最重要的画面 |
| 小格密排 | 急促、碎、慌乱 | 快速对话、连击动作 |

页内布局规则：
- 阅读动线 Z 字（左上→右下）或右开本倒 N 字，格与格间距引导视线：密=时间短，疏=停顿/呼吸
- **翻页揭示（页尾钩子）**：每页最后一格留悬念（台词半句/新元素入画），翻页第一格揭示
- 对话格：人物视线方向决定台词气泡顺序，避免视线交叉打架

### 动态版式（V3，硬性）

页漫禁止默认排成整齐 2x2，也禁止四格等宽等高地从页顶排到页底。每页提示词必须明确非对称布局：

1. **大小对比**：至少有一个大格和一个明显更小的小格；大格留给情绪、动作或揭示。
2. **错位格底**：相邻格的上下边界不要完全对齐，格底高度可故意差 4%–8%。
3. **出血与斜切**：动作页至少一格出血到页缘；冲击/爆发页可用斜切贯通格。
4. **满页 splash 稀缺**：只给章节最重情绪点，通常一章 0–2 页；splash 上边界可斜切上方小格。
5. **阅读顺序仍清晰**：布局可以乱，格序不能乱；必要时在提示词写“阅读顺序按格1到格4”。

页漫布局模板：

| 页型 | 布局要点 |
|---|---|
| 日常/对话页 | 页顶宽景 + 左右栏错位 + 页底一大一小，格距稍宽 |
| 蒙太奇页 | 左上窄竖格 + 右上宽扁格 + 斜向动作长格贯穿中段 |
| 冲突升级页 | 一角大格压迫 + 对角小格反应 + 页底出血宽格收尾 |
| 爆发动作页 | 斜切冲击大格出血 + 贯通速度格 + 底部大小格追压 |
| 情绪高潮页 | 上三分之一小格错落，其余为满页 splash，上边界斜切 |

## 每格字段（分镜脚本表格列）

| 字段 | 说明 |
|---|---|
| 格 ID | `CH001-G03-02` |
| 景别 | 远/全/中/近/特写 |
| 构图 | 视角、角色站位、视线方向 |
| 角色 | 每个出场角色 + 引用设定图 ID（如 `CHAR-林晚-三视图`） |
| 机位 | 引用场景机位图编号（如 `LOC-小巷-机位图#9 低机位`） |
| 表情/动作 | 具体到可画，不写抽象词 |
| 台词 | 原文逐字；标注气泡归属与类型（对白/呐喊/内心独白） |
| 旁白/音效 | 旁白框文字原文；拟声词 |
| 格间连续性 | 与前后格的视线、动作衔接说明 |

## 文字预算

- 每格台词 ≤ 2 句，超长对话拆格。
- 每页总字数（台词+旁白）≤ 60 字——图像模型渲染大段中文容易出错字。
- 章首金句当页眉旁白可选，问用户。

## 交付

《分镜脚本.md》按页分节（`## CH001-P003`），页内表格列格；每节表前写一句本页戏剧职责。
用户确认后进入 S4，禁止跳过分镜直接出页。

## 分镜脚本头部（frontmatter）与格大小分级

脚本开头写元信息，S4 与成书阶段都靠它：

```markdown
---
章号: CH001
版式: 页漫(3:4) / 条漫(9:16)
页数: 10
---
```

格大小分级（写进每格"格形"字段）：

| 级别 | 用途 |
|---|---|
| 满页 splash | 章节最重情绪爆点，全书 scarce |
| 半页 | 重要转折 |
| 1/3 格 | 标准叙事格 |
| 1/4 及以下 | 快速连续动作/对话 |

每页固定写入：`核心信息`（一句）、`页尾钩子`（悬念/半句台词/新元素入画）。

## 范围约束

拆分镜前先核对《角色出场总表》：本章出场的每个角色，身份是否已被后文点名修正？
设定图是否已补齐？角色引用错误（把 A 角色画成 B 角色）比重roll更贵，返工要整页作废。

## 节拍表先行（硬性，先于页数）

**页数是节拍密度的输出，不是先验输入。**禁止"一章≈9页"的惯性预算倒推内容——
那会把关键伏笔动作当成"过渡"砍掉，把高潮压缩成"一格跳变"。

**节拍表是落盘交付物，不是脑内草稿**：拆分镜前先把节拍表写入
`02-分镜/CH<章号>/节拍表.md`（逐拍一行：拍号/类型/内容/预计格数），S3 停靠时随分镜脚本
一并交付。分镜脚本 frontmatter 的页数字段必须与节拍表推导一致（写"由节拍表第 X–Y 拍推导，
共 N 页"），先写页数再填内容的分镜视为无效，必须返工。

拆分镜前先列本章 beat sheet（节拍表）：

1. **逐拍列出**：每个动作/台词/情绪转变一行，标注类型（日常/冲突/伏笔埋设/伏笔回收/高潮）。
2. **高潮展开成最小节拍**：高潮禁止一格带过。变身/升级/觉醒类场面的最小节拍模板——
   信物/契机出现 → 情绪或能量催化 → 宣言/决意 → 力量回应（光效/异象） → 逐步呈现（服装/形态，≥1格） →
   **变身后的第一动作** → 亮相台词。合计至少 1.5–2 页。
3. **伏笔双向检查**：埋设拍必须有画面（"收起/藏匿"动作），回收拍必须有画面（"取出/兑现"动作）；
   登记进《伏笔与关键道具表》，两端缺一即断链。
4. **按节拍定页数**：信息可压缩（旁白合并、蒙太奇），但伏笔拍与高潮拍不可压缩。

分镜完成后自检三问：本章高潮给够节拍了吗？本章埋的伏笔画出"埋"的动作了吗？
前章埋的伏笔在本章回收时画出"兑现"动作了吗？

## 检查清单落盘（硬性，S4 的参考图校验依据）

分镜定稿后，把每页引用的资产 ID 汇总写入 `02-分镜/CH<章号>/检查清单.md`：

```markdown
# CH001 检查清单
| 页 | 引用设定图 ID（人物） | 引用场景/机位图 ID | 备注 |
|---|---|---|---|
| P001 | CHAR-林晚-三视图、CHAR-阿泽-三视图-幼年 | LOC-教室-机位图 | 幼年形态缺图→P0，出页前必须补 |
```

规则：
- 每格出现过的每个**形态**单独核对（"第3格幼年林晚" 引用 `CHAR-林晚-三视图-幼年`，
  不是成年三视图）；清单里出现任何 ❌ 缺图项，S3 不算完成，禁止进入 S4。
- 机位图按触发条件核对（单章 ≥2 页出镜的场景必须有 `LOC-xxx-机位图`）。
- S4 出每页前由该表自动推导参考图清单（见 page-generation-guide.md），禁止手工凭记忆配图。

每次任务只拆用户点名的**一章**；拆完确认后出页，本章出完即停靠，不自动续下一章。
下一章的请求从本章末尾的连续性备注（轴线、服装、时段）接起。
