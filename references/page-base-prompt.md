# 漫画页基础提示词（每页必带）

每页漫画的提示词 = 本文件的基础段 + 该页分镜内容 + 一致性段 + 去AI味条款。

## 页面规格

- 类型：多格漫画页，竖版 3:4（条漫 9:16）
- 格线：黑色 1–2px；格间白沟 8–12px；格形有大小节奏（见 storyboard-guide.md 格形语言）

## 文字元素规范

| 类型 | 样式 | 用途 |
|---|---|---|
| 对话气泡 | 椭圆白底、黑边、尖尾指向说话人 | 台词 |
| 呐喊泡 | 尖刺边缘爆泡 | 呐喊、大招 |
| 旁白框 | 矩形、奶黄/浅色底 | 旁白、时间地点 |
| 思考泡 | 云朵形+泡点拖尾 | 内心独白 |
| 字幕条 | 贴格边缘的横条 | "三年后…"类转场 |

- 中文文字：全角标点，手写感字体（不要印刷体）；单泡 ≤ 12 字优先
- 文字层级：格内台词清晰可读优先级最高，装饰性文字不得压过台词

## 提示词三段式结构（一致性核心）

```
[角色参考]
参考图1为主角三视图，参考图2为场景全景。本页出场角色：
- 主角：<识别锚点逐字复用（发型/眼/服装色板）>

[页面内容]
页漫 6 格：上排横宽格2格（场景建立+行走）、中排……（逐格：格形/镜头/角色动作/表情与状态锚点——
表情跟剧情节拍写具体动作，光源方向/台词逐字与气泡归属）

[一致性提醒]
角色外貌严格依据参考图，不得改动发型、发色、服装款式与配色；
画风遵循风格基因：<线稿+上色+色板+媒介质感五段摘要>；
媒介质感：轻微纸张颗粒/杂志网点；光源方向：右侧低角度逆光；
构图：核心格偏左上，留出翻页钩子格。
```

## 提示词信噪比（写法三原则）

1. **肯定句主导**：画面要什么直接写进逐格内容——具体可见的动作/表情/状态
   （血污、嘶吼、眼神方向、颤抖）。肯定句是提示词里最大的力，负面清单只是配重；
   肯定句方向写错（如称帝格写"娇俏脸颊"），堆多少负面都救不回来——先改肯定句。
2. **负面按需配重**：日常格 2-3 条"避免"足矣；只有场景本身强推某效果时
   （变身风暴、魔法爆发页）才加对冲性负面。负面连堆 5 条以上＝顺从性过载，
   画面要么过素要么乱飘，本身就是 AI 味。
3. **配额**：必须满足 ≤4 条、避免 ≤3 条，只留真正致命的；尺寸/质量/模型走接口参数
   不写进提示词；不堆"铁律/最高优先级"式强调词。

## 去AI味条款（每次生成自检）

1. 空质量词（masterpiece/8k/超高清）与泛风格词（动漫风/唯美）禁止出现
2. 每页至少：1 种媒介质感锚 + 1 个明确光源方向 + 1 处非居中构图
3. 人物带 2 项不完美（碎发/褶皱/不对称）；表情按剧情节拍写具体动作而非"在说话"；
   台词逐字给出，生成后放大校对错字
