# S2 设定图生成方法

目标：把《设定总表.md》变成一组可当参考图用的 PNG。设定图是全书一致性的锚，
宁可慢，不可糊。

## 描述考古（出图前必做）

设定图提示词的事实唯一来源是原著文本，不是模型印象。为任何角色/形态出图前：

1. **全文检索**：用本名 + 别名 + 代称 + 变身名（如"角色本名/昵称/变身代号"）在原著全文里
   检索该角色的所有段落，重点摘外貌、发型发色、瞳色、体型、服装、随身物、气质描写。
2. **按时间线归并**：同一角色在不同章节/形态下的描写分别归档（幼年/成年、便服/变身），
   前后文矛盾时以后文点名为准并记录差异，禁止混写。
3. **写描述档案**：汇总进《角色出场总表》的角色档案卡，标注每条描写的章节出处。
4. **留白处置（硬性，禁止自动补全）**：检索不到的属性明确标注"原著留白"，**出图暂停**，
   向用户提交补全决策表，每个候选方案必须包含四项：
   - 设计依据（个人色呼应/场景约束/原著间接线索）；
   - **剪影冲突检查**：与全部已出场角色逐一对错（同发色系？同发型轮廓？撞了就废）；
   - 采纳后的连带重roll范围（哪些已生成页面会与新设定图不符）；
   - 不采纳的后果。

   由用户拍板后，把结论写回描述档案再恢复出图。两条禁忌：
   - **禁止循环锚定**：不得以"与已生成页面一致"为补全依据——该页面若诞生于
     无设定图阶段，其特征本就是无据自由发挥，锚定它＝把错误合法化
     （典型事故：某角色原生发色原著留白，早期页面在无参考图时误借已出场角色的
     发色，设定图反向锚定后两个角色剪影相撞，整批资产返工）；
   - **禁止静默补全**：不得以"合理推测"名义自行定值——哪怕标注了"补全"字样，
     未经用户拍板也算违规。
4. **提示词只引用档案**：设定图提示词的每一条外貌描述都能指回某章原文；找不到出处的
   特征一律不写。跨年龄段角色（幼年→成年）出多张设定图，每张只锁自己形态的特征。

## 人物设计三原则（出设定图前自检）

1. **剪影可辨**：把角色涂成纯黑剪影仍能认出是谁（发型轮廓+体型+标志物）。主要角色互相之间
   剪影必须有明显差异（高矮/胖瘦/发型体积）。设定图交付前过一遍剪影测试。
2. **识别锚点 3–5 个**：跨页一致性靠 2–5 个高辨识锚点（如"眉下疤+红围巾+单侧马尾"），锚点写进
   人物卡并逐字复用进每页提示词。锚点贵精不贵多，多于 5 个模型记不住。
3. **体型矩阵**：主要角色在身高/体型二维上互相错开，避免全员同脸同高。

## 提示词统一结构

每条提示词按六段写，顺序固定：

1. **画风基准**：原样复制《设定总表.md》的画风基准段
2. **主体与身份锚点**：角色/场景的外貌事实（从人物卡/场景卡搬运）
3. **变体说明**：这张图固定什么（三视图/表情集/全景）
4. **构图与视角**：三视图为正/侧/背全身等高；场景为广角 establish shot
5. **背景与光线**：设定图用纯色或极简背景，避免环境喧宾夺主
6. **禁止项**：不出现台词文字、水印、多余角色；全身入画比例统一

每条提示词同时执行 [style-guide.md](style-guide.md) 的去AI味清单：负面词清零、人物至少注入
2 项不完美（碎发/褶皱/不对称）、带媒介质感锚、光源写方向。设定图虽是纯背景，也要写
`轻微纸张颗粒质感` 一类媒介词，与后续漫画页质感一致。

## 人物设定图类型

| 类型 | 用途 | 要点 |
|---|---|---|
| 三视图 | 主参考，所有漫画页引用 | 正/侧/背全身，同高同比例，中性表情 |
| 表情集 | 情绪戏多的角色 | 6–9 宫格常见表情，五官锁定不变 |
| 服装变体 | 场景切换频繁的角色 | 同脸同发型，只换装 |

主要角色至少出三视图；表情集、变体按剧情需要补。

## 合并角色设定图（characters.png，S4 每页必传）

三视图之外，把**全部主要角色拼成一张** `设定图/人物/CHARACTERS-全员.png`：

- 每个角色一行：正面 + 表情差分（中性/喜/怒/惊 四格小图）
- 每个角色下方标注姓名标签；白底；每角色自带色板色块
- 用途：S4 每页生成时，"全员图"恒定作为参考图 1（一图管全员一致性），
  出场角色的三视图按需加传。这样"参考图 ≤ 3 张"的预算就够了。

## 角色文档（characters.md）

`01-设定/角色文档.md` 按此模板为每个主要角色建档（S2 出图依据，S4 提示词锚点）：

```markdown
## CHAR-林晚（示例）
- 角色/年龄：男主，17 岁
- 外貌：脸型/发型（颜色+长度+分缝）/眼（色+形+特征）/体型/识别锚点（疤、饰物…）
- 服装：默认装（具体到款式褶皱）+ 场景变体
- 个人色板：主色 #xxxxxx / 辅色 #xxxxxx / 点缀 #xxxxxx
- 表情差分：中性=…；喜=…；怒=…；惊=…
- 年龄变体（如剧情跨年龄段）：幼年=…；成年=…
```

## 场景设定图类型

**机位图触发条件（量化，硬性）**：满足任一条件，场景必须出 3x3 机位图——
- 单章内出镜 **≥2 页**（如停车场连出 3 页）；
- 跨章复用（第一章做过的教室，后续任何章再用）；
- 同场景内出现机位变化镜头语言（俯视→低机位→反打）。

只有单章单页出镜的一次性场景可以只出全景图。

- **全景图**（必须有）：establishing shot，交代空间结构和标志物
- **机位图（空间锚定，按上述触发条件强制）**：一张 **3x3 九宫格**，画**同一空间的 9 个不重复机位**：

  | # | 机位 | 语义 |
  |---|---|---|
  | 1 | 高位俯视 | 看整体布局（房间/巷道的平面关系） |
  | 2 | 正面广角 | 主视角 |
  | 3 | 左前45° | 中景 |
  | 4 | 右前45° | 中景 |
  | 5 | 电影主机位 | 标准镜头，空间中部 |
  | 6 | 反打机位 | 对面视角（与 2 相对） |
  | 7 | 内部向外 | 窗边/门口看向内（或门洞内看向外） |
  | 8 | 侧面横向 | 平移镜头视角 |
  | 9 | 低机位 | 地面向上（戏剧化仰视） |

  - 每格角上标**数字 1–9**（单字符渲染不易出错）；机位含义的图例写进场景卡与分镜脚本
  - **标志物跨格一致**：电线杆、门、窗、黑板等在每格的位置关系必须自洽——这正是锚定目的
  - 用法：S4 出页时传机位图，分镜每格直接标"机位#N"，提示词声明
    "本格镜头=机位3（左前45°中景），角色从 A 向 B 移动"；需要更精确时裁切对应格单独作参考
  - 命名：`LOC-<场景>-机位图.png`
- **时段变体**（按需）：同一场景的日/夜/雨等光线版本，空间结构不变

## 生成与落盘

1. 用内置 `image_gen` 工具生成；一次调用一张图。
2. 生成后把选定图移动/复制到 `01-设定/设定图/人物/` 或 `场景/`，按 ID 命名。
3. 在 `生成日志.md` 追加一行：ID、提示词全文、参考图（设定图阶段通常无）、状态。
4. 重roll 时旧版文件名加 `-v2` 保留，日志里记录用户不满意的点。

## 交付前自查

逐张检查：外貌锚点全中、无违禁元素、画风与基准一致、三视图三人等高。
