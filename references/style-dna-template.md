# 风格基因文档模板

S1 确认后，为每部小说写一份《风格基因.md》放进 `01-设定/`。它是全书所有出图提示词的
"画风基准段"来源。模板如下（借鉴知识漫画领域的画风规格实践）：

```markdown
# 风格基因 —— 《小说名》

## 基底配置

- 基底画技：manga-color ｜ manga-bw ｜ ligne-claire ｜ ink-brush ｜ realistic
- 情绪基调：neutral/warm/dramatic/romantic/energetic/vintage/action
- 题材预设：都市校园 / 修真玄幻 / 悬疑灵异 / 历史古风 / 无
- 版式：页漫（3:4 竖版）/ 条漫（9:16）

## 线稿规格

- 外轮廓：粗细、是否勾白边；内结构线：粗细
- 质感：顺滑/手绘抖动/毛笔飞白；密度：高/中/低

## 角色设计规范

- 头身比：写实 7–8 头身 / 少年漫 6–7 头身
- 眼型：大眼表达系 / 写实系；瞳色规则（如"主角眼色=点缀色"）
- 表情符号体系：汗滴/怒纹/青筋 全书统一一种画法

## 时代地域锚点清单（防"日式教室穿帮"）

场景的时代与地域必须落成**具体道具清单**，出场景图时逐项带入，生成后对照自查：

```markdown
## 地域锚点（示例：2010年代中国高中）
- 教室：白墙、墨绿水泥黑板、密排双人课桌、后墙黑板报、吊扇+荧光灯管、
  课程表/标语横幅、塑料窗帘、扫帚拖把角
- 街巷：水泥电线杆、防盗窗、空调外机、小广告残留、下水井盖
- 禁止无脑套用：日式木地板教室、欧式路灯、不属于该地域的招牌字体
```

## 背景处理

- 日常戏：简化（色块+少量细节）
- establishing 场景：细节拉满
- 情绪格：抽象渐变/网点/速度线

## 上色方式

- 上色法：赛璐璐平涂 / 厚涂 / 水墨 / 网点（黑白漫写明：58%平网/渐变网/沙网用途）
- 阴影色规则：偏紫褐 / 偏棕 / 纯灰；禁纯黑描边阴影

## 默认色板（HEX 必填）

| 角色/角色 | 主色 | 辅色 | 点缀 |
|---|---|---|---|
| 主角 | #xxxxxx | #xxxxxx | #xxxxxx |
| 女主 | #xxxxxx | #xxxxxx | #xxxxxx |
| 世界观点缀色（超凡元素专用） | #xxxxxx | | |

## 视觉元素

- 气泡样式：对话=椭圆白底尖尾；旁白=奶黄矩形框；思考=云朵；喊叫=尖刺爆泡
- 效果线：集中线/流线/速度线的使用场景
- 媒介质感：纸张颗粒 / 杂志印刷网点 / 干净数码（去AI味锚，全书统一）

## 质量标记（生成后逐项自查）

- ✓ 角色发型/服装色与色板一致
- ✓ 光源方向符合本章设定
- ✓ 媒介质感可见（网点/颗粒）
- ✓ 无空洞质量词污染的"AI 完美感"（过滑、居中对称、均匀光）
```

> 出图时，把「线稿规格＋上色方式＋色板＋视觉元素＋媒介质感」五段原样拼进每条提示词开头。
